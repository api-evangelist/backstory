# Backstory (formerly People.ai)

> Backstory is an AI revenue intelligence platform for sales leaders, CROs, and revenue teams. It automatically captures customer interactions across email, meetings, calls, chat, and CRM, maps that activity to open deals, and answers the questions revenue leaders actually ask — which deals are real, which are at risk, and what to do next. Rebranded from People.ai in April 2026. Backed by ICONIQ Capital, Andreessen Horowitz, and Lightspeed Venture Partners.

## Agent surface

Backstory ships a hosted, remote MCP server. It is the company's only public machine-callable surface — there is no published OpenAPI, GraphQL SDL, AsyncAPI, or A2A agent card on any Backstory or People.ai host.

- MCP endpoint: https://mcp.people.ai/mcp (canonical protected resource: https://mcp.backstory.ai/mcp)
- Transport: JSON-RPC over Streamable HTTP
- Auth: OAuth 2.0 authorization_code + PKCE (S256), dynamic client registration; or PAI-Client-Id / PAI-Client-Secret request headers for programmatic clients
- Authorization server metadata: https://mcp.backstory.ai/.well-known/oauth-authorization-server
- Protected resource metadata: https://mcp.backstory.ai/.well-known/oauth-protected-resource/mcp
- Permissions: a connected client sees exactly the records the authenticating user can already see in Backstory Engagement Dashboards; no elevated access
- MCP overview: https://help.backstory.ai/en/articles/15252736-backstory-mcp
- MCP marketing page: https://www.backstory.ai/platform/mcp

### Tools (13, as published by Backstory)
- Find Account — search for an account, return matching records, opportunities and related CRM data
- Find Record by CRM ID — resolve a CRM record id to an account or opportunity
- Top Records — the accounts and opportunities ranked highest by engagement and admin prioritization
- Account Status — summary of risks, sentiment, key topics and recommended next steps
- Opportunity Status — deal-level summary of risks, momentum and suggested actions
- Scorecard — retrieve Closeplan / qualification scorecards, questions and answers
- Recent Account Activity — recent emails and meetings on the account
- Recent Opportunity Activity — communications and meetings on a specific opportunity
- Engaged People — internal and external contacts in recent communications
- Account Company News — earnings calls, SEC filings and public company reporting
- Ask Sales AI About Account — account-level analysis over CRM data, activity, engagement and scorecards
- Ask Sales AI About Opportunity — opportunity-level analysis over full deal context
- Situation Search (beta) — up to four historically similar deals, with actions taken and outcomes

## REST API

A Backstory REST API exists but is not publicly documented. Administrators generate, pause and revoke up to five API key/secret pairs in the Backstory Admin Panel; no base URL, reference, or specification is published.
- API key management: https://help.backstory.ai/en/articles/15252717-api-key-management
